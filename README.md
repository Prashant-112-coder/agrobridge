# AgroBridge AI

AgroBridge is an agriculture-focused application combining web technologies with geospatial and environmental data to support farm insights.

## Highlights

- Agriculture-focused workflows
- Node.js and Express backend
- Google Earth Engine integration
- NDVI-based vegetation information
- Farm-oriented data processing

## Development

Keep service credentials in environment variables and never commit API keys.

## Status

The project is under active development.
