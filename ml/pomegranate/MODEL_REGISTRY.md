# Model registry

No production pomegranate model is registered yet.

A model can be promoted only after:

1. Dataset audit passes.
2. Train/validation/test leakage checks pass.
3. Held-out test metrics are recorded.
4. Unknown/rejection behavior is measured.
5. Model card and dataset provenance are stored.
6. Field validation is planned before production claims.

Expected first artifact: `pomegranate-fruit-v1`.
