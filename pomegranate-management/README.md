# Pomegranate Management System

A full-stack farm management starter for pomegranate growers: crop stages, disease and pest knowledge, scouting, irrigation, nutrition, activities, expenses, harvest, sales, alerts and an image-diagnosis API seam.

## Stack
- React 19 + Vite
- Express 5 REST API
- PostgreSQL schema included
- No secrets committed

## Run frontend
`npm install`
`npm run dev`

## Run API
`npm run server`

The UI works in demo mode without PostgreSQL; API endpoints are ready for persistence integration.

## Safety
Disease/treatment guidance is educational. Product choice, dose, label compliance and local registration must be verified with current agricultural guidance and a qualified agronomist.
